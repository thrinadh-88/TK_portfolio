# Assets Directory

Place the following files here before deploying:

| File | Description |
|------|-------------|
| `profile.jpg` | Your personal photograph (recommended: 400×400px, square crop) |
| `resume.pdf` | Your resume PDF |
| `projects/p1-screenshot1.png` | Business Dashboard screenshot 1 |
| `projects/p2-screenshot1.png` | Student Performance Prediction screenshot 1 |

## How to update content
Edit `../data/portfolio-data.js` — all personal info, skills, projects,
certifications, and internships are centralized there.

## Contact Form
Open `app.js` and set `FORM_ENDPOINT` to your Formspree / Basin URL.
Example: `const FORM_ENDPOINT = "https://formspree.io/f/xpwzabcd";`
