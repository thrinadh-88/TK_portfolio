# Project Screenshots

Place your project screenshot images here.

Naming convention:
- p1-screenshot1.png  → Business Sales Dashboard screenshot 1
- p1-screenshot2.png  → Business Sales Dashboard screenshot 2
- p2-screenshot1.png  → Student Performance Prediction screenshot 1
- p2-screenshot2.png  → Student Performance Prediction screenshot 2

Then update the `screenshots` arrays in `data/portfolio-data.js`:

```js
screenshots: [
  "assets/projects/p1-screenshot1.png",
  "assets/projects/p1-screenshot2.png",
],
```
